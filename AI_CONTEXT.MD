# Development Workflow

## One Chat = One Feature

Rules

1. Read AI_CONTEXT.MD completely before starting.

2. Work on ONLY ONE FEATURE in a single chat.

3. You may modify ONLY the files required for that feature.

4. Never modify unrelated features or modules.

5. If additional files are required for the current feature, explain why before modifying them.

6. Complete the current feature 100% before moving to another feature.

7. Preserve existing architecture and business logic.

8. Do not refactor unrelated code.

9. At the end provide:
   - Feature completed
   - Files created
   - Files modified
   - Reason for each modified file
   - Verification completed
   - Production-ready status

10. Wait for my approval before starting the next feature.

11. All explanations must be in Bangla.
