# PART 9 — HR / Attendance / Leave / Payroll Frontend Integration

## Implemented
- HR workspace now loads staff, shifts, attendance, leave types, leave requests and payroll history from existing APIs.
- Daily attendance tab with date selection and Present / Absent / Half Day / Late actions.
- Leave management tab with employee/leave type selection, date range, reason, submission and manager approval/rejection.
- Monthly payroll tab with month/year selection, real payroll generation endpoint, totals and itemized payroll results.
- Existing employee registration and outlet-scoped staff roster preserved.
- Existing HR backend models, validation and deterministic payroll calculations preserved.

## Important
- No fake attendance/payroll figures are generated by the UI.
- Payroll uses `/hr/payrolls/generate` and the existing backend calculation engine.
- This part does not modify finance calculations or bypass authorization.
